# 写作控制系统 v1 · Implementation Plan

> **For Hermes:** 本计划为规划文档，不执行代码。写作建设/试写仍冻结，需用户另行授权后才开始执行。

**Goal:** 把已验证的 19 指标评分体系反转为写作控制系统——评分标准→写作规则→目标画像→大纲/章节/场景前置评审→Writer→Critic→Rewriter→终评，先跑通 1 本短篇端到端。

**Architecture:** 双轨架构。正式 19 指标只做全文终评（效标）；另建场景级写作控制指标（从写作规则派生，与 19 指标解耦）做局部前置评审。指标→写作规则采用"模板先行并行"：先建通用五件套转换模板 + 管道框架，规则内容等 v4.1/v4.2 定稿后灌入。

**Tech Stack:** 复用现有评分器（minimax-cn/MiniMax-M3，blindwriter profile 凭证）+ Hermes 多 Agent 编排（Writer/Critic/Rewriter 三角色）+ 语料统计校准（G3 后）。

## 3. 目标架构（用户建议 + 阶段 11 整合）

```text
题材/创意
    ↓
目标评分画像（先验模板，G3 后校准）
    ↓
故事设计（金手指/主线/人物弧光）
    ↓
全书大纲评分（19 指标全篇级预测）
    ↓
大纲修正（≤2 轮）
    ↓
章节规划（章节目标画像）
    ↓
章节目标评分（写作控制指标前置检查）
    ↓
场景/beat 设计（章→场景→beat）
    ↓
场景骨架评分（写作控制指标，骨架 <80 分不写正文）
    ↓
Writer 写正文（不看评分细节，保证文字自然）
    ↓
Critic 评分（严格按写作控制指标，输出五件套：分数/扣分证据/问题位置/修改策略/修改优先级）
    ↓
问题定位
    ↓
Rewriter 定向修改（只针对 Critic 指定问题）
    ↓
再次评分（Critic 复评）
    ↓
通过（循环 ≤3 次，防指标过拟合）
    ↓
全文终评（19 指标全篇级效标）
    ↓
进入下一章
```

**三角色映射（与阶段 11 整合）：**
- Writer = Terra（作者）：大纲、正文、修改——只消费具体写作规则，不看评分细节
- Critic = Luna（编剧+评审）：严格按评分体系评价，输出五件套，不能随便发挥
- Rewriter = Terra 的子流程：只针对 Critic 指定的问题修改
- Sol（总编）= Director：选题、目标画像、终审、全局约束

## 4. 关键架构原则（防指标过拟合）

1. **Writer 不看评分细节**：Writer 只接收"写作规则 + 目标画像 + 当前场景骨架"，不接收 Critic 的分数和证据。保证文字自然。
2. **循环 ≤3 次**：Writer → Critic → Rewriter → Critic 最多 1-3 次，不无限循环。
3. **双轨隔离**：场景级写作控制指标 ≠ 19 指标。19 指标是全篇级效标，场景级指标是生产控制。两者解耦，避免"迎合评分器"。
4. **骨架先于正文**：场景骨架 <80 分不写正文，先改骨架。减少废稿。
5. **评分系统不负责告诉 Writer"怎么写每一句话"**：只控制故事结构和发现偏差。

## 5. 核心转换模型：指标→写作规则五件套

每个正式 19 指标转换为可执行写作规则，五件套结构：

```
评分指标（正式 19 指标中的一项）
  ├─ 扣分原因（从 G2 分歧诊断和锚点倒推：什么样的文本会在这项上失分）
  ├─ 写作原则（正向原则：什么结构容易在这项上得分）
  ├─ 可执行动作（具体可执行的写作动作，如"每个核心场景必须存在明确的'人物目标—阻碍'"）
  ├─ 修改动作（Critic 发现问题后的定向修改指令）
  └─ 场景级写作控制指标（从写作规则派生，用于局部前置评审，与 19 指标解耦）
```

**示例（B09 核心冲突强度 → 写作规则）：**

```
B09 核心冲突强度
  扣分原因：连续两场景只有信息交流没有利益冲突；冲突升级后立刻完全解决
  写作原则：每个核心场景必须存在明确的"人物目标—阻碍"；连续两个场景不能只有信息交流没有利益冲突；每章至少发生一次局势变化；冲突升级后不能立刻完全解决；场景结尾优先留下新的威胁、选择或信息差
  可执行动作：写场景前先填"目标-阻碍表"（主角目标 / 阻碍方 / 阻碍方式 / 局势变化 / 结尾悬念）
  修改动作：Critic 发现"第 X 段冲突停止发展"→ 删除解释性对白、在对手第二段对白后增加一次实质性威胁、将背景信息隐藏进冲突
  场景级写作控制指标：场景冲突完整性（目标-阻碍对是否明确、局势是否变化、结尾是否留悬念）
```

## 6. 场景级写作控制指标（双轨，与 19 指标解耦）

从写作规则派生，用于场景/章节级前置评审和局部评审。先验设定，随试点迭代：

| 场景级指标 | 定义（0/5/10 三档） | 关联 19 指标（用于终评对标，不解耦混用） |
|---|---|---|
| 目标-阻碍对 | 场景内主角是否有明确目标 + 可识别阻碍 | B08 主角目标明确度 / B09 核心冲突强度 |
| 利益冲突 | 场景是否至少有两次针对性回应（对手有反应） | B02 冲突出现速度 / B09 |
| 局势变化 | 场景结束时状态是否与开始时不同 | B18 中段塌陷 |
| 悬念钩子 | 场景结尾是否留下新威胁/选择/信息差 | C01 开篇钩子强度 / N7 |
| 爽点节奏 | 压抑铺垫→爆发释放的节奏是否符合目标画像 | B30 压抑铺垫 / B31 爆发释放 / B33 小爽点密度 |
| 信息差/潜台词 | 对话中是否隐含未明说的信息 | N6 对话潜台词密度 / B03 信息差 |
| 人物动机 | 场景内人物行动是否可被动机解释 | C14 代入感综合 |
| 情绪张力 | 场景是否推动读者情绪（期待/紧张/共情） | B36 共鸣触发器 / N3 强情弱写 |

（此表为先验草案，需在试点中按"指标通用性硬约束"审计：定义/阈值/流程必须通用，不为一本书定制。）
