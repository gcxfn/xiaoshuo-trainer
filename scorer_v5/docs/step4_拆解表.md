**N 计数权裁决（v5.1 最终版）**：
- LLM **不报 offset**（offset 是程序能百分百确定的东西）。
- LLM 只报：`round_quotes`（两回合逐字引文）+ `nearby_anchor`（邻近锚点）+ 语义判定。

- 引文定位失败 → 该件 `evidence_mismatch`，不计入 N。

## 全局结论（v5.1）

1. **全部 L/K/offset/比例/阈值/0-5-10 映射 → 全部 Python**（Step 5 Python 事实层）。
2. **LLM 输出中不再出现 L/K/F/offset/最终 score**——LLM 只报语义判断 + 逐字引文 + 邻近锚点，offset 全部由 Python 在 canonical text 中定位生成。
3. **19 项均已尝试操作化，暂不预先归为 SUBJECTIVE**（修正：不得提前宣布全部客观）。
4. **N 计数权（N6/B33）**：LLM 报事件结构（引文+锚点），Python 定位 offset 后合并去重计数——根治 v4.0"LLM 自估 K/N"问题。
5. **混合项模式**（LLM 标候选 + Python 算比例/计数/排序/选场）为 v5 通用执行模式。
6. **待验证项**（Dev10/Cross-model/Human-human 前不下结论）：B09 利害等级、B36 核心驱动/轴归类、C22 动机一致/演讲式判定、B23 终局主动。
