## 0. 全局规则、隔离与统一单位

### 0.1 状态和隔离

1. 本文件是冻结的 v4.0.0 正式执行规则；不得替换 v3、改写候选、回填历史结果或把不同版本分数合并。
2. 评分 worker 只能看到本发布锚点、当前授权卡的匿名去首行正文和无标签输出模板；不得看到商业档位、阅读量、标题/作者映射、metadata、台账、split、历史评分、gold、另一张卡、统计报告或项目其他目录。
3. 示例只解释边界，不是预置答案、单篇例外或规则替代。任何规则变化都必须升 v4.x、保留旧版和旧结果，并重新走适用的验证门。
4. 每个指标只输出 `0 / 5 / 10`。每个判定项均须逐字引文或可复核位置；缺证据记为不成立，不以题材常识、作者意图或整体印象补足。

### 0.2 正文、位置和场景的唯一口径

**输入首行剥离。** 构建侧以 UTF-8 读取原始文本，删除首个物理文本行（包括该行的行终止符）作为首行标题；删除前的原始字节只在受限构建侧留存并计算 hash，删除的行及任何标题映射不得进入评分 worker。后续本发布包所称 `text` 均指剥离后的正文；首行缺失、材料异常或删除会造成正文损失时，构建侧拒绝该材料并按授权抽样规则替换，不得由评分员自行修补。

**正文字符。** 对完整正文 `text` 使用 Python Unicode 码点计数：

```python
import re
L = len(re.sub(r"\s+", "", text))
K = L / 1000
```

`\s` 按 Python Unicode 正则语义移除所有空白码点；标点、全角字符和普通字母保留。编码、原始长度、`L`、`K`、统计脚本/命令以及首行剥离结果的唯一机器可验证承载位置，是构建侧受限审计 sidecar，遵守 `构建侧输入审计.schema.json`；该 sidecar 不是评分 JSONL，不挂载给评分 worker，也不得合并进评分记录。标题、作者、文件名和章节元数据不属于正文。

**位置。** 原文位置用 1 起始的场景号、自然段号和正文 Unicode 码点起止偏移表示；引文最多三行。计数剔除空白，但位置不得重排。章节标题、纯分隔行不计自然段；若正文格式使其作用不明，记录原始位置并标记边界，不得静默猜测。

**连续场景。** 先按正文顺序切分全文：同一时空、围绕同一冲突目标的连续段落为一场；时空、对手或冲突目标改变即切场。单段内发生切场按句切分。场景清单必须有编号、起止位置、时空、冲突目标和切分理由。

**连续叙述块。** 同一场景内的连续叙述段落为一块；若句间切换为另一角色不可由他人得知的感知/想法，按句拆分。混合块无法唯一拆分时标记“无法唯一归属”，不得整块归给焦点角色。

**可识别实体。** 角色可通过专名、稳定称谓/昵称、唯一身份描述或全文唯一的第一人称焦点“我”指认；角色不必自报姓名。“他/她/对方”在存在多个可能实体且无法唯一指认时不成立。非人实体只有在正文明确赋予可识别行动主体时才可列入，不把环境或抽象概念当角色。评分表写出实体指代及成立依据。

**主角方与对手方。** 主角方是主角本人，或明确为维护主角利益而行动的可识别盟友；对手方是压制、伤害或欺骗主角方的一方。不得仅按善恶、题材惯例或结果反推双方。

**主线冲突。** 先列出所有候选冲突：双方/实体、冲突目标、建立位置、双方可观察状态、最终结果位置。核心主线从“已建立且正文最终明确解决/确定归属的候选”中选择最早建立者；若同一候选有多个结果，取最后一个不可逆确定结果的位置。没有明确最终结果时，记录“无可识别终局”，不得用情绪最强或最后一段代替。该主线清单是 B02、B09、B16、B34、B36、C22 等指标的共同输入，不得由待评分指标结果反推。

**统一证据表。** 每项评分必须按“候选清单 → 位置/实体 → 逐字证据或状态前后值 → 判定项成立/不成立 → 计数/算式 → 0/5/10 → 排除项与不确定项”的顺序输出。相同证据在相同规则下必须唯一落档。

### 0.3 非重叠责任

- B08 测“目标是否明确及目标链是否由主角自主维持”；B23 测“主动行动的数量、依赖和终局发起”；同一行动可被两项引用，但必须分别满足各自字段。
- B02 测最早合格对抗及其位置；B31 测终局/清算场的四项结构；二者不以同一指标的分数替代另一项判定。
- B03 测信息不对称设置；N7 必须另有蓄意投放、错误决定和损失三链。
- B16 测结尾闭环；B34 测可见清算场；C22 汇总组件但引用已登记证据，不凭综合印象新增结论。

## 1. B01 异常事件出现位置

### 1.1 定义、证据和判定

异常事件是打破主角原有日常或预期的**外部事件**，包括超常设定显形、死亡/逮捕/背叛揭露/身份暴露/事故、命运级消息送达等。内部情绪、渐显不适、日常摩擦和单纯内心决定不计。先按正文顺序列全部候选，取最早满足定义者；同句并发事件按正文首次出现的可观察起点排序，无法排序则并列留档。

记录首个候选的首句、自然段 P、正文码点起点、`L`、位置比例 `q=起点/L`，并摘出异常后一个可观察行动/决策句及因果窗口。即时改变要求异常后同一场景内，主角在异常之后作出与异常有直接连接的行动或决定；仅“感到震惊/害怕”不算。

判定项：① `P≤3`；②异常在同一场景内直接改变主角行动/决定；③首句位置 `q≤10.00%`。

### 1.2 计分、示例与流程

按互斥优先级落档：

1. 无合格异常，或 `q>10.00%`：**0 分**；
2. `q≤10.00%` 且 ①、②、③ 全成立：**10 分**；
3. `q≤10.00%` 但未同时满足 ①和②：**5 分**。

这样先处理“无事件/超过10%”，不会出现 10 分与 0 分路径重叠。示例：第2自然段出现“门外传来逮捕通知”，主角立即交出钥匙并改道，且位置≤10%，三项全中为10；第7段出现同类消息且主角立即行动，位置≤10%但①不成立为5；前500字只有“我心里发沉”，首个外部事件在15%后为0。

流程：全文场景清单→候选异常清单→首句/P/偏移/比例→行动改变句与因果窗口→按优先级判定→落档。不得用锚点书读法替代证据。

## 2. B02 冲突出现速度

### 2.1 定义、证据和判定

合格对抗性冲突要求至少两个可识别实体围绕同一事项立场相左，并完成至少两个“行动/陈述→针对性回应”的交换。单方宣布、纯内心不满、未点破误会不计。功能人员按章办事的流程摩擦不计，除非从明确的羞辱、驱逐、利益阻断或其他利害对撞点开始。前置楔子/闪回摘要仅在明确写出双方立场、同一事项和实际对撞结果时计入；只有“后来发生争执”的概述不计回合。

一个回合是甲的可识别言语/动作后，乙针对该言语/动作的可识别回应；乙→甲为下一回合。单方独白、广播、无回应动作不构成第二回合。记录双方、事项、两个回合引文、首回合码点位置和核心冲突同源证据。

判定项：①首合格冲突首回合≤500码点；②首回合位置≤全文15%；③事项与独立主线冲突清单同源。多人、非人实体和即时文字聊天均按可稳定指认实体及正文时间序列执行；异步留言须明确即时往返才计。

### 2.2 计分、示例与流程

- 无合格冲突或首回合位置 `>15.00%`：**0 分**；
- 首回合 `≤500` 且③成立：**10 分**；
- 首回合 `≤15.00%` 但未满足上一条：**5 分**。

若首回合≤500但不与核心同源，按5分；若首回合>500但≤15%，按5分。示例：门卫明确阻止主角取回已付款物品，主角提出权利主张并得到反驳，两轮交换且事由连接主线，自首回合≤500为10；首屏只单方宣布退出，后文才出现两轮交锋，则按合格冲突实际位置判分；纯“前台按规定核验”无利害对撞，不计。

流程：列主线候选→全文列冲突候选→验证实体/事项/回合→记录位置→判①–③→落档。不得先用“冲突激烈”选择对象。

## 3. B03 信息差设置

### 3.1 定义、证据和判定

核心秘密必须同时满足：与主线冲突直接相关；至少一方主要角色明确不知道而读者或另一角色知道；其埋设、揭开或利用在正文有可定位状态变化。每条秘密强制五格：内容、知方、不知方、首次可观察投放位置、状态变化/利用场景。角色“知道”只能由叙述明示、明确反应、使用该信息或后文揭示支持；读者推断不算。

①多层咬合：至少两条不重复秘密，且知情主体或功能不同；②反制底牌：主角方在转折前已持有、目标方未被公开的可验证信息/能力/凭证，并有亮牌或利用场景；③信息差驱动转折：秘密揭开或被利用后紧接改变主线目标、关系、资源或计划之一。普通世界观背景、未改变状态的设定不算秘密。

### 3.2 计分、示例与流程

- ①与②同时成立，或①与③同时成立：**10 分**；
- 恰好一项成立，或②与③成立但①不成立：**5 分**；
- 0项：**0 分**。

示例：读者知道文件被替换、主角知道备份凭证而对手不知道，并在终局用凭证改变归属，三项成立为10；只有一条身份隐瞒且揭开后改变关系，③成立但①不成立为5；双方从开篇就同步知道全部事实为0。

流程：列秘密→填五格→去重并确认主体→判底牌和转折前后状态→计①–③→落档。B03 的信息链不能代替 N7 的蓄意操控链。

## 4. C01 开篇钩子强度

### 4.1 四项规则

只检查正文前500个非空白 Unicode 码点，标题不计。先固定边界，若一条证据跨边界，只计前500码点内可观察部分。四项均须逐字证据：

①悬念缺口：前500码点可写成一个具体“谁/为何/会怎样”问题，且后文有明确事件或陈述回答，并记录问题位置和解答位置；
②高概念反常：改变日常规则或主角生存、身份、关系状态的可观察设定。重生、互换、系统、身份调包、倒计时、重大罪案只是示例，不是封闭题材清单；现实主义异常同样可计；
③即时压力：前500码点有可识别截止时间或不可逆后果，且主角当前行动受其约束；
④信息效率：前500码点各有一条焦点角色身份线索和核心冲突目标/阻碍线索，二者须能由文本直接指认。

### 4.2 计分、示例与流程

4项成立为**10分**；2–3项为**5分**；0–1项为**0分**。示例：前500码点写明“今晚封门”、主角身份和被替换的资格，并留下“谁改了名单”的问题，若后文回答则四项全中；只有“还有十五分钟”及可辨身份、冲突而无改变日常规则的高概念，3项为5；只有情绪氛围和模糊不安，≤1项为0。

流程：截取前500码点→逐项列引文→回看后文核验悬念解答→列身份/冲突两格→计项→落档。不可用标题补齐身份或悬念。

## 5. B08 主角目标明确度

### 5.1 目标、行动链和因果

先列前1/3内所有目标句：台词或明确心理决定，表达主角要达成、守住或查明的具体事项。按“贯穿主线且决定终局”的固定规则选择核心目标；没有可选目标则①不成立。行动一环是主角方主动选择/发起的事件并产生可观察结果；同一目标、同一时空的连续动作合并，独立结果或新选择才另计。主角委托他人只有在正文有可观察委托、结果回到主角决策链时计入；他人自行送证、先知信息和巧合不计。

①目标句可摘；②行动链至少3环，逐环写“行动→目标服务关系”；③因果自主：写出行动前状态、行动句、行动后变化及终局前转折连接，至少一处转折由主角行动而非他人代劳/巧合直接促成。短篇即使一环完成闭环，也不因“高效”自动视为三环；证据不足按规则不成立。

### 5.2 计分、示例与流程

3项为**10分**；2项为**5分**；0–1项为**0分**。示例：主角明确“保住资格”，先查档、再取得回执、再公开提交材料并因此改变裁定，10；目标句和两环行动存在但关键证据由他人偶然送达，5；只有被动离场或情绪决定，无目标链，0。

流程：列目标句→按固定规则选核心目标→列行动环及前后状态→核代理行动→查转折因果→计项落档。B08 不按终局爽感倒推目标清晰度。

## 6. B09 核心冲突强度

### 6.1 主线冲突、利害和贯穿

使用全局主线冲突清单，禁止用结局结果反推未建立的矛盾。利害对象采用题材中立的状态轴：人身安全/自由、关系归属、资源控制、名誉或制度资格。等级：L3=已发生或迫近的死亡、长期剥夺自由、子女/身份归属丧失、终身性损害、实质名誉/制度资格毁灭或同等不可逆后果；L2=重大财产/资源损失、婚姻或关键关系存废、长期但可逆的人身/资格限制；L1=短期口角、轻微利益、一般面子或可即时修复的摩擦。须列状态前后及具体后果，等价结构按后果而非题材命名映射。

①利害≥L3；②零和：双方争夺同一不可并存状态控制权，一方获得即排除另一方，且引文显示无共同实现路径；可谈判或可兼容目标不算零和；③贯穿：从主线建立场景起，按场景清单统计，完全没有该冲突目标、状态变化或回应的连续区段不得超过全文非空白码点的30.00%。

### 6.2 计分、示例与流程

3项为**10分**；2项为**5分**；0–1项为**0分**。示例：双方争夺唯一制度资格，失去者将被永久取消且冲突从开篇持续到裁定，10；婚姻存废、双方明确互斥且贯穿但属于L2，5；一次性拌嘴可和解、无持续状态对象，0。

流程：列候选主线→列利害状态前后→定L级→判零和→按场景列表算完全搁置比例→计项落档。不得把 B31 的场景项或商业结果当 B09 证据。

## 7. B16 结尾闭环度

### 7.1 结尾范围、否决和三项

先列开篇承诺/核心意象、主线冲突和全部主要对手，再检查结尾连续场景。结尾部分以最后一个正文场景开始向前取全文最后15.00%码点作为扫描范围，但闭环对象以场景清单为准，不把比例本身当作结局。

直接0分否决：V1=结尾出现求赞、点赞、断更等元话语；V2=结尾另起与主线无关的新事件并以其替代主线结果。否决须逐字定位。无否决时判：①开篇承诺/核心意象在结尾以同一功能的场景或明确陈述回收，须并列两处证据；②主线胜负/关系/归属在结尾以人物在场的交锋、清算、裁决或明确行动呈现，纯事后通报不成立；③先列主要对手清单，结尾对每个对手给出可确定最终状态；多线文本逐条核对，开放结局如实标记未闭合，不因缺少传统审判自动判坏。

### 7.2 计分、示例与流程

命中否决或仅1项成立为**0分**；无否决且2项为**5分**；无否决且3项为**10分**。示例：开篇反复出现的门锁在结尾由主角亲手更换，双方在场完成资格裁决且全部对手状态交代，10；线索和主线裁决有场景但开放结局未确定某一对手，5；最后用“后来一切顺利”概述，未形成场景且无回收，0。

流程：列开篇承诺/意象→列主线和对手→锁定末15%扫描范围→先扫V1/V2→并列证据→逐项计数→落档。否决字符计数与全局非空白码点口径一致。

## 8. B23 主角能动性

### 8.1 行动、依赖和终局

主动行动是主角方主动选择/发起行为并造成可观察状态变化；内心决定未行动、被动反应、环境顺势位移和他人代劳不计。同一目标、同一时空连续动作合并；新选择或独立结果才新计。每条行动记录位置、发起者、动词、前状态、后状态、直接证据。团队行动按可观察发起者和主角利益归属记录，授权代理须有委托句和结果回流。

①行动数≥5；②递进链至少2处：后一行动的输入必须是前一行动新产生的可观察资源、信息、关系或位置，写出两端证据；③终局主动：决定性场面由主角方发起，写出发起动作及其前后状态。策略性拒绝或不行动只有在正文明确该选择造成状态变化时计入。

### 8.2 计分、示例与流程

3项为**10分**；2项为**5分**；0–1项为**0分**。示例：查证、设局、取得凭证、公开提交、触发裁决五条均由主角主动发起，且两条输入链和终局发起清楚，10；行动足够但关键证据全由他人送来，无两处依赖，5；仅一次改签离场且无终局发起，0。

流程：列全部候选行动→合并连续动作→填前后状态→判主角方归属和代理→找依赖链→核终局发起→计项落档。不得以 B08 的目标句代替 B23 行动证据。

## 9. B30 压抑铺垫充分度

### 9.1 事件、升级和克制

压抑事件是对主角方造成具体侵害、贬损或委屈的事件，必须有受害实体、动作/发生事实和直接后果。按同一时空、同一受害对象或同一冲突目标切分；同一动作的多种后果合并，完全重复的回忆不新计。每条记录前状态、侵害动作、后状态、位置和逐字引文。

①事件≥3起；②升级：相邻或可比较事件中至少出现范围扩大、程度加深、施害者升级或不可逆后果加重之一，并列出前后状态；③克制呈现：直白情绪/说理块为连续≥51个非空白码点、主要为情绪标签或抽象控诉，且无新的外部动作、对话交换或感官输入；全文≤2块，同时至少两起计入事件的主要证据是事实动作/物件/结果而非情绪标签。该定义不以题材形式排除心理、职场、幻想或非人叙事。

### 9.2 计分、示例与流程

3项为**10分**；2项为**5分**；0–1项为**0分**。示例：三次可定位的资格剥夺、孤立和资源扣留，后期后果不可逆，叙述靠事实细节且无长篇控诉，10；三次同型排斥但无范围/程度/施害者/后果升级，5；只有一次辱骂和数字化情绪宣言，0。

流程：全文列事件→按边界去重→填前后状态→比较升级→用固定码点数扫描宣泄块→判计数项→落档。不得把“很压抑”作为证据。

## 10. B34 大爽点存在

### 10.1 清算场选择和四项

先按场景清单列全部候选清算场。终局场优先取“最后一次不可逆确定主线冲突归属/结果”的场景；没有该场时，按冲突目标列所有实时交锋，取最后一个可确定主线结果的场景；不存在可确定结果时记录无清算场，不以情绪最强补选。并列场全部留档。

①当众性：至少3个可识别角色实体在场，或正文明确有可识别群体围观；稳定称谓/唯一身份描述可计，不要求自报姓名。②对手当场挫败：受罚、失态、被带走、归属落空或其他后果在场景内可见。③主角方触发：主角方的可观察言行直接引爆，不由旁白、巧合或事后转述替代。④不可逆代价：当场或紧邻连续段落出现法律制裁、身份揭穿、关系断绝、制度资格丧失、核心资源不可恢复损失等前后状态变化；仅“大家很震惊”不成立。

### 10.2 计分、示例与流程

①与④均成立且四项至少3项为**10分**；至少3项但缺①或④为**5分**；恰2项为**5分**；≤1项或无合格场为**0分**。示例：公开裁决中三名实体在场，对手资格被撤销，主角提交证据触发且关系终止不可逆，10；主角在电话中揭穿对手并使其失去资源但无三人/群体在场，5；只有旁白说对手后来受罚，0。

流程：全文列候选场→按最后不可逆结果选场→记录实体和实时性→逐项证据表→并列场留档→计项落档。B34 不把“爽”或音量作为判据。

## 11. B36 共鸣触发器

### 11.1 题材中立的关系冲突轴

删除“现实关系原型才计”的题材门槛。B36 扫描的是可观察的关系冲突轴，任何现实、幻想、悬疑、职场、行动或制度环境均可通过等价状态证据计入；纯背景设定、抽象主题或一句评价不计。每类至少一处有人物/实体、事件动作和直接后果的场景。

六个互斥优先归类轴：P1偏置/区别对待（同等资格被不平等分配）；P2背叛/边界越界（承诺、关系或授权被破坏）；P3不公/污蔑/替代（责任、身份、成果或资格被错误归属）；P4强制义务/情感或信念绑架（以关系、道德、制度或信仰压迫选择）；P5权力不对等伤害/排斥（利用权力施压、剥削、封锁或集体排除）；P6付出/贡献被抹除（可观察劳动或牺牲被隐匿、挪用或不承认）。同一事件命中多个轴时，按“直接后果最具体”的一个主轴归类；并列时依 P1→P6 固定顺序，不能重复计类。

①命中至少2个不同轴；②核心驱动：至少一个命中轴与全局主线候选的状态变化同源，且至少两个主线场景由该轴冲突直接改变目标、关系、资源或计划；③跨轴广度：命中轴中至少包含一个 P1/P3/P4，或在不使用这些名称时由同等的偏置、不公替代或强制义务状态逐字证明。③不是受众“广谱”判断，而是文本内第二个关系冲突轴的固定映射。

### 11.2 计分、示例与流程

3项为**10分**；2项为**5分**；0–1项为**0分**。示例：幻想议会中继承资格被偏置分配（P1），主角功绩被他人冒领（P3），并有强制效忠（P4），且其中两轴推动主线，10；只有一次关系背叛但无第二轴，5；抽象描述“世界残酷”而无事件场景，0。

流程：列六轴候选→每轴列场景/实体/动作/后果→按互斥优先级去重→引用主线状态变化→计①–③→落档。不得因题材是纯架空而排除关系冲突，也不得用受众常识代替文本证据。

## 12. C22 整体质量

### 12.1 否决和独立组件

C22 是可复核组件的组合，不测文笔、商业表现或整体印象。先做否决：V1=结尾连续超过200个非空白码点、主要为演讲式总结/人生感悟且无新的场景行动，或出现求赞/元话语；V2=核心冲突被巧合、无铺垫的突然悔悟、降智或外力直接解除。每个否决须记录连续块边界和引文；开放结局只记终局项未满足，不自动判V2。

无否决时填四张独立证据表：①支线闭合：开篇建立的至少两条线索/支线各有结尾状态，开篇和结尾证据并列；②动机一致：主角及核心对手关键决策可回指正文已建立动机、资源或信息，不出现无证据转向；③三幕完整：开篇钩子、按场景可观察的中段推进、终局结果三者均有位置，使用本候选同一主线清单，不引用商业标签；④终局强度：终局场按本候选 B31 的四项证据表计数至少3项且含交锋回合和不可逆决定。若 B31 在独立评分中无合格终局场，④不成立；C22 不重新凭印象选场。

### 12.2 计分、示例与流程

命中任一否决或四项≤2项为**0分**；3项为**5分**；4项为**10分**。示例：两条开篇线索均回收、动机链和三幕清楚、终局场交锋与不可逆决定均有证据，10；前三项成立但开放结局无清算场，5；末尾200码点以上只作总结且无行动，直接0。

流程：锁定主线/支线/对手清单→否决扫描→四组件逐表取证→复用已登记场景与证据→计项→落档。C22 只能最后计算，不得用自己的分数反过来定义 B09/B16/B31。

## 13. N3 强情弱写

### 13.1 峰值、窗口和极限词

列出全书所有可观察情绪峰值候选（情绪状态或关系状态发生最大改变且有位置/前后状态）。每个候选必须记录场景、位置、变化前后状态和逐字承载证据。按“改变主线情绪或关系状态”→“后果不可逆性”→“后文明确回指”排序；同序并列全部保留，并对每个并列候选执行同一计数。选定峰值两侧各200个非空白 Unicode 码点的窗口；跨段按正文码点连续截取，窗口不足则记录实际长度。

①峰值可定位：候选有明确状态变化和唯一位置；无候选为0分。②直给词收敛：窗口内直接描述极限情绪强度的词计数≤2。词表固定包含“嘶吼、撕心裂肺、目眦欲裂、崩溃、痛不欲生、嚎啕大哭、歇斯底里、绝望、狂喜、欣喜若狂”等；同一词每次出现计一次，否定/引用他人说法仍按字面出现计数，隐喻不计。③承载转译：窗口有动作、物件、声场、静默或短句等可观察承载，且情绪状态与其因果可指认；仅形容词不成立。④主角本体收敛：主角若有宣泄，窗口内无上述极限词直接描述其本体，或其反应主要由动作/物件/短句承载；配角宣泄不替代③。

### 13.2 计分、示例与流程

4项为**10分**；3项为**5分**；0–2项为**0分**。示例：主角收到裁决后只回复“好”，同时关掉灯、收起证件，窗口无词表极限词，四项成立为10；峰值位置明确且有动作承载，但配角连续使用三项极限词，3项为5；主角“撕心裂肺地嘶吼”且无动作承载，≤2项为0。

流程：列峰值候选→固定排序并保留并列→切窗口→词表计数→判承载与主角反应→计项落档。N3 不把“主角必须冷静”当独立审美判断。

## 14. N6 对话潜台词密度

### 14.1 潜台词事件和数字链

潜台词事件至少含两个“甲可识别陈述/行动→乙针对性回应”的回合，且同一组交换满足：表层字面与真实意图相反或显著超出；真实意图至少由动作、第三方反应或后文明确揭示之一支持；交换围绕同一博弈目标，连续对话只计一件，出现新博弈目标才拆为新件。广播、单方独白、仅读者推断的机锋不计。与 B02 的区别是 N6 必须满足言此意彼和解码证据，B02 只需立场对抗。

数字链固定为：`L=len(re.sub(r"\s+", "", text))`，`K=L/1000`；`N`为逐件清单，每件列位置、双方、两回合、字面意、真实意、解码证据；`F=N/K`，保存原始 `F` 并以两位小数展示。正文为空或K=0时输入无效，不输出分数。

### 14.2 计分、示例与流程

冻结阈值：`F<0.20`为**0分**；`0.20≤F<0.50`为**5分**；`F≥0.50`为**10分**。示例：甲以闲聊问句施压，乙以礼貌回应回避，后文行动明确双方在谈是否终止合作，构成一件；若全文L=4000、N=2，则F=0.50，按10分路径；该数字只作边界演示，不是正文答案。

流程：统计正文→列回合→合并/拆分事件→四格记录字面/真实意/解码证据→算L/K/N/F→按左闭右开阈值落档。本版本已将该阈值冻结；后续修改必须升 v4.x 并重新登记。

# 边缘5指标（统一纳入 v4）

## 15. B31 爆发释放强度

### 15.1 定义、四项与计分

B31测全书是否存在合格的摊牌清算，不测音量或哭喊。按全局场景清单筛选：主角方与对手方为可识别实体并直接对峙；同一空间、实时电话/视频或正文明确即时往返的文字聊天；至少两个“行动/陈述→针对回应”交换。预录音播放、事后通报、回忆转述、纯内心和单方自述不计。回合表记录回合号、发起实体、目标实体、引文和回应。

逐场判：①至少两名可识别实体实时完成两回合；②主角方当场执行无法撤回的关系、法律、归属、程序或核心资源决定；仅说“我要”而未执行、摔自己物品泄愤不计；③外部具体声响/光影/温度/气味/触感/物件状态变化；情绪隐喻和“全场震惊”不计；④场景前有同源矛盾/压迫/损失铺垫。取最高项数，所有并列最高场留档；无场或最佳≤1项=0分，恰2项=5分，≥3项且含①②=10分，≥3项缺①或缺②=5分。

### 15.2 示例和流程

面对面裁决中主角出示已提交凭证，对手反驳后被拒，门锁声和前文同源欺骗均可定位，四项为10；实时聊天两轮互问，只有忙音而无不可逆决定/铺垫，①③为5；只有旁白称公司翻盘，无实时对峙，0。

流程：全文场景→摊牌候选→实体/实时性→回合表→四项证据→最高场及并列→落档。

## 16. B33 小爽点密度

### 16.1 定义、终局和四类证据

独立小爽点必须同时满足胜负可见、主角方主动、终局外当场闭环。胜负证据至少一类：A1对手受挫反应（语塞、改口、僵住、退让、离场或计划落空）；A2对手基于假象信任/得意/放松/轻敌；A3第三方明确倒向主角方或质疑对手；A4主角方当场取得钱、证据、地位、承诺或关键信息。每类须逐字证据。

终局按全局主线规则：最后一个改变主线最终归属/结果的冲突目标场景；开放结局或无明确最终归属则无可识别终局，不排除场景。事件按因果连续段合并：同一主动动作及连续反应只计1；新的主角主动行动且产生独立A结果才新计；计划、内心嘲讽、离开且无A证据不计。

### 16.2 数字链、计分和流程

`L=len(re.sub(r"\s+", "", text))`，`K=L/1000`；列每个事件的编号、位置、主动动作、A代码、引文和闭环；`F=N/K`，保存原始值并显示两位小数。`F<0.60`为0分；`0.60≤F<1.20`为5分；`F≥1.20`为10分。K=0时输入无效。

示例：一次布置引出对手改口、旁观者质疑并取得文件，A1+A3+A4同属一个动作，N只加1；先用假消息引其站队、再独立启动程序取得凭证，两次行动各有A证据，计2；只有“我不再道歉”无A证据，不计。

流程：全文场景→主线终局→终局外候选→A证据→合并拆分→L/K/N/F→阈值落档。

## 17. C14 代入感综合

### 17.1 焦点角色、正向项和否决

连续叙述块按全局规则切分并记录角色、位置、非空白码点数；A/B/C及X/Y的每个判定均须保留逐字证据或可复核位置。焦点角色按直接感知/想法块所在场景数最多者确定；并列比较直接块码点总数；仍并列取首次出现者并留档。

A身体化细节：焦点角色的动作或身体感受；B感知通道：环境/他人信息明确经由焦点角色感官进入；C心理呈现克制：连续≥51非空白码点、主要抽象解释价值/因果/主题，且不含推动场景的可观察行动、对话交换或新感官输入，全文≤2块。C列全部候选及计/不计理由。

X/Y任一命中即0：X1至少两个角色有直接内心块且非焦点块占全文严格>30.00%；X2不依附角色的全知旁白块占比严格>30.00%。Y1任意连续500非空白码点内至少3个乱码块；乱码块含U+FFFD或Unicode类别Cc/Cs/Co的非空白码点。Y2普通叙述碎片化单位占全文严格>70%，单位为每个仅一个完整句/独立分句且相邻空行隔断，排除对话、列表、代码、诗歌等；Y3明确整段缺失/顺序冲突且至少一块语义无法由相邻文本重建。全角数字、零星错别字和对话一行不自动命中。

### 17.2 计分、示例和流程

命中X/Y为0分；无否决且A/B/C成立0–2项为5分；三项为10分。示例：唯一第一人称焦点即使无姓名也可成立A/B；短于51码点反思不计C；含新动作/感官输入的长反思不计C；对话每句一行不计Y2。

流程：场景/叙述块→焦点选择→A/B/C候选→X/Y分子分母→先否决→正向计数→落档。

## 18. B18 中段塌陷

### 18.1 端点、状态和阈值

列全文连续场景。开篇钩子是正文顺序中首次使主线冲突可识别的场景，多候选取最早；最终高潮是最后一次不可逆确定主线冲突归属/结果的场景，多候选取最晚；无端点则不排除并记录理由，两端同场只排除一次。中段为全部场景减去实际识别的端点，报出分母清单。开放结局不能把最后一段机械认作高潮。

每个中段场景填：边界、冲突目标、状态类别、变化前状态、变化后状态、逐字证据、有效性。四类为新信息、关系翻转、资源得失、计划进退。只有前后状态不同且有证据才有效；重复施压/拒绝、等待、回忆、环境描写和仅有决定准备意图无效。一个场景多类仍只计一个有效场景。

`无效占比=无效中段场景数/中段总数`，精确比较：≥50%或连续无效≥3为0分；≥25%且<50%且无连续≥3为5分；<25%为10分。中段总数为0时记录端点清单，无效数=0、比例约定为0，走10分路径，但必须在 held-out 复核。

### 18.2 示例和流程

连续三场重复要求道歉/重复拒绝且前后状态不变，连续无效≥3为0；收拾行李仅是意图不计，实际拿票离开或被扣下导致资源/计划改变才有效；开放结局无不可逆结果时不排除最后场。

流程：全文场景→主线冲突→钩子/高潮端点→中段分母→逐场状态前后和证据→有效性→比例/连续段→落档。

## 19. N7 角色间认知操控

### 19.1 三方、四格和三要件

先枚举每个候选做局：操控者刻意使受骗者形成错误认知，受骗者据此作出决定，决定造成可观察实质损失。主角反操控、配角受骗、第三方受损均可计；直接暴力/伤害而无错误信息环节不计。一次性蓄意性由伪造/编造准备、明知真相仍投放、投放后获益或明确有目的安排任一项证明；巧合、误会或读者知道不算。长期人设须有至少两个场景维持证据。

每局填四格：①意图/知情；②受骗者实际接收的假信息/伪装；③错误认知下的具体行动，或有机会、知悉选择却因错误认知不行动；④行动后地位、财产、人身、关键关系或计划败亡的实质损失。缺任一格，决策闭环不成立。

三要件：①载体至少两类，从C1当面言语、C2第三方之口、C3道具文书、C4行为模式伪装、C5信息屏蔽中计不同类；②同一假信息/人设在至少两个不同场景投放或维持；③四格闭环完整。

多局按字典序选择：成立要件数（3>2>1>0）→③闭环完整→跨场景投放/维持场景数→可观察损失数量。完全同序全部留档。0要件=0分，1–2要件=5分，3要件=10分。

### 19.2 示例和流程

伪造文件加两次当面哭诉，投资人据此汇款且款项被转走，三要件为10分；一次编造导致店主离岗失窃，只有一类载体、无重复，闭环虽成但仅1要件为5分；偶然听到断章形成误会，无蓄意投放为0分；直接把人推出门没有错误信息环节，不计N7。

流程：候选做局→三方与蓄意性→四格证据→C1–C5分类与去重→跨场景/闭环→多局字典序→计分。不得用 P8 单卡或读者同情选择做局。
